# License Decision

## Current decision

Do not add a `LICENSE` file at this stage.

The owner confirmed written clearance for public GitHub publication of newly written clean-room code, generalized documentation, diagrams, synthetic fixtures, examples, and tests. That publication clearance is distinct from authority to grant reuse rights, and no license addition was separately approved.

## Effect

This package must not be described as open source. If it is eventually published without a license, readers should not be told that reuse is permitted.

## Decision required for any later license

Before adding or changing a license, separately decide:

1. whether the code may be published;
2. whether reuse rights may be granted for that code;
3. whether documentation and diagrams have the same or a different licensing scope;
4. whether third-party dependencies or assets impose notice obligations.

License selection should be based on the cleared artifact and intended permissions, with appropriate legal review where needed. This file is a governance record, not legal advice.
